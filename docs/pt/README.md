# Original records (Portuguese)

These are the working records and pre-registrations for this measurement, kept
in the language they were written in. They are not translated here on purpose:
the sha256 seals in the author's `SELOS.txt` refer to these exact files, and
translating them would break the hashes that make the record verifiable.

| file | what it is |
|---|---|
| `PREREG_VOLCOMP_INK.md` | pre-registration, round 1 (w043), sealed before measuring |
| `PREREG_VOLCOMP_CURVA_Q.md` | pre-registration for the q curve, round 1 |
| `REGISTRO_VOLCOMP_INK.md` | record of round 1, with the 2026-09-10 erratum documenting three instrument defects, their correction, and the re-measurement |
| `REGISTRO_VOLCOMP_CURVA_Q.md` | q curve of round 1 as measured on 2026-09-08, marked superseded |
| `REGISTRO_VOLCOMP_W035.md` | record of round 2 (w035), including the planted noise control and the inference-footprint finding |

The README at the repository root carries the results and the method in
English. Nothing in these files contradicts it; they hold the detail, the
failed hypotheses and the corrections.
